# Portfolio Website

A responsive, modern single-page portfolio website.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Replace the portfolio title and intro copy in `index.html`.
- Update project names and descriptions in the Featured work section.
- Replace `hello@example.com` with your email address.
- Update the LinkedIn, GitHub, and Instagram links in the footer.
- Adjust colors and typography in `styles.css`.
